# MovieSearch

A movie discovery app built with Next.js and TMDB API.

## Live Demo

[View Live](<https://explorecinema.vercel.app/>)

## Features

- Browse popular movies
- Search movies with debounced input
- Loading, empty, and error states
- Movie detail page

## Tech Stack

- Next.js 16
- Tailwind CSS
- Axios
- TMDB API

## Getting Started

1. Clone the repo
2. Install dependencies
   npm install
3. Create .env.local and add your TMDB API key
   NEXT_PUBLIC_OMDB_API_KEY=your_api_key
4. Run the dev server
   npm run dev

## Deployment

Deployed on Vercel.
